# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| main    | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability or hooking defect in dll-forward-gen:

1. **Do not open a public issue.**
2. Report the vulnerability privately through [GitHub Security Advisories](https://github.com/negg0s/dll-forward-gen/security/advisories/new).
3. If GitHub Advisories are unavailable, contact the maintainer directly via GitHub contact channels.

### Please Provide:
- A description of the issue and potential impact.
- Affected commit, function, or SDK header.
- Reproducible steps or proof of concept.
- Target Windows version and compiler used.

### Response Timeline
- Initial acknowledgment within 48 hours.
- Status update and patch evaluation within 7 days.
- Public release published after a fix is verified.
